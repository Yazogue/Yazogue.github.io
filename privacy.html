Privacy Policy – MonPipelineTikTok

Last updated: 13 November 2026

What data is used

When the owner signs in with TikTok, the tool receives an access token and the basic profile information TikTok provides (open ID, display name, avatar), plus the creator information needed to post (allowed privacy levels, interaction settings, maximum video length).

How it is used

This data is used only to publish videos to the owner's own TikTok account and to show the account name in the tool. It is not used for advertising, profiling or any other purpose.

Storage and sharing

Tokens are stored only on the owner's own computer. No data is sold, shared with third parties or sent anywhere other than TikTok's official API. The tool has no other users and collects no data about viewers.

Deletion

Revoking the app in TikTok (Settings and privacy → Security → Manage app permissions) invalidates the tokens; the owner deletes the local token file at the same time.
